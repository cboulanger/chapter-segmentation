# Experiment history — main chapter-segmentation workflow evaluation

This is the archive of superseded evaluation snapshots and follow-up
investigations for `RESULTS.md` (the main `chapter_segmentation` workflow:
the pure heuristic, the strategy pipeline, and the standalone
heuristic/outline/LLM strategies). `RESULTS.md` keeps only the latest/
current numbers for each topic; whenever a run or finding there is
superseded by a newer one, the full write-up moves here and `RESULTS.md`
keeps a short summary plus a link into the matching heading below. Nothing
here would be "wrong" or obsolete in the sense of being unreliable at the
time it was measured -- each entry stands as an accurate record of what a
specific run found, kept in full so the reasoning and dead ends behind the
current numbers aren't lost.

**Currently empty** -- every section in `RESULTS.md` as of this writing
still describes its most recent run directly, so nothing has been
superseded yet. Add a `## <heading>` here, matching `RESULTS.md`'s own
heading text, the first time a section there needs to compress an old
snapshot into a summary+link.

For the three not-yet-integrated experiments this file used to also cover
(`dnb-toc-only` ground-truth generation, the layout-based TOC/chapter-
first-page classifier pilot, and the NuExtract fine-tuning pilot), see
their own dedicated files under `evaluation/experiments/` instead --
`evaluation/experiments/dnb-toc-ground-truth.md`,
`evaluation/experiments/toc-classifier-pilot.md`, and
`evaluation/experiments/nuextract-finetuning.md` -- each of which now
holds both its current status and its own full history in one place
(moved there 2026-08-19, see `evaluation/RESULTS.md`'s "Scope" note).
